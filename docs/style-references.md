# Референсы стиля (от Чопы, 08.11.2026)

Общее: вертикаль 9:16, кинетическая типографика (крупные слова появляются по одному),
плавные наезды камеры, свечение, быстрые смены под бит, ограниченная палитра.

1. arpit_clipsyk (агентство) — жёлтый/белый градиент + чёрный, «пилюли» и строка поиска
   с текстом (Ads / Follow-up / Connected), скриншоты сайтов и таблиц летят в 3D, печатающийся текст.
2. saas.wave — 3D-сцены в розово-белом, предметы летают (сложно кодом, только как ориентир).
3. neuromedia_ai — тёмный фон, неоново-салатовый акцент, жирный шрифт капсом, HUD-интерфейс,
   плашки-выделения слов, таймлайн с кадрами. Русский текст.
4. marvix.motion — кремовый фон, вырезанные фото-коллажи, оранжево-красные заголовки,
   сочетание гротеска и рукописного курсива.
5. zhanyeka.iy — серый/красный/чёрный, ч/б коллажи в стиле постера, сжатый шрифт капсом,
   плашки под углом, чек-листы с крестиками. Русский текст.
6. aslaniedits — чёрный + жёлтый, светящаяся точка ведёт текст, вертикальные полосы-переходы,
   крупный узкий шрифт-логотип.

План: Промонтаж — стиль 3 (тёмный + тёплый оранжевый акцент); ролик-проблема — стиль 4/5 (коллаж);
кофейня — стиль 1/6 (жёлтый + чёрный).
